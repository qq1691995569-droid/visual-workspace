# 家居产品图质感还原重绘（线稿 + JSON 材质光影方案）

## 一、技能定位

专门针对家居小家电产品场景图，解决 AI 多轮迭代后出现的**偏色漂移、材质失真、家具质感塑料化、光影走样**问题。

采用「线稿锁定构图 + JSON 结构化材质/光影属性」控制方案：

1. **图一（构图定稿图）→ 线稿图**：提取画面轮廓线稿，作为构图确定依据
2. **图二（风格参考图）→ JSON 反推**：以 JSON 格式反推图二的**材质属性**（重绘材质依据）与**场景光影**（光线依据）
3. **最终提交**：线稿图 + JSON 提示词 → 生成新的重绘图片

在完全保留定制的人物姿态、产品位置、画面构图的基础上，精准还原参考图的真实家居质感、自然光影与标准色彩。

**实测结论（重要）**：默认提交格式为「**线稿图 + JSON 提示词（不含参考图）**」——画面更干净、构图更稳、材质更统一。仅当该格式仍无法还原参考图色彩/材质时，才把图二作为第二参考图叠加（三要素格式）。

## 二、适用场景

- 家居暖风机、塔扇、除湿机等小家电产品图 AI 迭代后的偏色校正
- 保留画面构图不变，批量统一全屋家具材质、色彩与光影风格
- 去除 AI 生成图的塑料感、油画感，升级为真实商业摄影质感
- 同系列产品主图、场景图的风格色调标准化统一

## 三、前置素材准备（必须 2 张图）

| 素材 | 角色 | 要求 |
| --- | --- | --- |
| 图一：构图定稿图 | 线稿构图来源 | 构图、人物姿态、产品摆放符合需求，但色彩/材质失真 |
| 图二：风格参考图 | JSON 材质/光影来源 | 色彩准确、材质真实、光影氛围符合预期 |

素材缺失或只有一张图时，先向用户说明缺口并请求补齐，不自行编造。

## 四、执行流程

前置依赖：读取 `dreo-visual-lab` 技能确认连接与模型可用性；`dreo_client.py` 位于该技能 `scripts/` 目录。本技能依赖 Python 图像库（PIL / numpy / OpenCV），缺失时先安装。

### 第 1 步：图一 → 线稿图

**两种生成方式，优先方法 A（GPT 2.5 生成），OpenCV 作为备选。**

#### 方法 A（推荐）：GPT 2.5 高质模型参考图生成线稿

实测结论：OpenCV Canny 线稿过于骨架化、大物体轮廓不完整；**GPT 2.5 生成的「纯轮廓线稿」构图锁定更干净、家具轮廓完整**，是当前最优方式。

1. 先把图一上传到 DREO，取得 `COMPOSITION_KEY`：

```text
python dreo_client.py upload <图一路径>
```

2. 提交 GPT 2.5 高质线稿任务（`count=1`，`ratio` 与图一一致）：

```json
{
  "tool_type": "conversation-image",
  "params": {
    "prompt": "<线稿生成提示词>",
    "image_paths": ["<COMPOSITION_KEY>"],
    "route_override": {"provider": "openai", "model": "gpt-image-2.5-sunburst"},
    "interactive": false,
    "count": 1,
    "resolution": "2K",
    "ratio": "<与图一一致的比例>"
  }
}
```

**纯轮廓版提示词模板（默认推荐，只留轮廓、无排线）**：

```text
将参考图转换为一张简洁的室内家居场景黑白轮廓线稿图（pure outline line art）。
要求：1) 严格保持参考图的画面构图、所有物体的位置、人物姿态、透视关系不变；
2) 只用干净、流畅、连续的外轮廓线勾勒每个物体，不要任何排线、阴影、明暗、体积排线或填充；
3) 必须完整勾出大物体轮廓：【按画面列出全部大物体：沙发、人物、边几、风扇、柜体、雕塑、台灯、装饰画、落地窗、纱帘、地毯等】；
4) 白底黑线，画面干净利落，无文字、无水印、无多余杂物、无灰色阴影。
```

**精细排线版提示词模板（备选，需要表现体积时用）**：把上模板第 2 条改为「可用少量细腻排线表现体积与明暗，但不要涂成实心黑色」，并注明各家具结构线（扶手与椅腿、柜门纹理、风扇机身结构）。

3. 轮询下载线稿后，先肉眼检查：大物体轮廓是否完整、构图是否与图一一致；不达标则调整提示词重跑。

#### 方法 B（备选）：OpenCV Canny 线稿脚本

调用技能自带脚本（通用参数版，支持中文路径）：

```text
python scripts/make_lineart.py <图一路径> <输出线稿图路径>
```

脚本逻辑：灰度 → 高斯降噪 → Canny 边缘 → 白底黑线（默认阈值 60/150、膨胀 1 次）。若 OpenCV 读中文路径失败会自动回退 PIL。

线稿图用于锁定：所有物体轮廓、位置、人物姿态、画面构图、透视关系。
- 线稿过密影响生成 → `--canny-low 80 --canny-high 200` 或 `--dilate 0`
- 重要轮廓丢失 → 降低阈值或 `--dilate 2`
- 仅当 DREO 无 GPT 额度或用户明确要求快速方案时使用

线稿生成后需上传获取 `LINEART_KEY` 供后续步骤使用（见第 4 步）。

## 五、核心参数与效果调优

| 控制项 | 推荐数值 | 作用 |
| --- | --- | --- |
| 线稿参考权重 | 0.8 ~ 0.9 | 保障构图、人物、产品造型不跑偏 |
| JSON 材质权重（提示词比重） | 高 | 逐项约束材质、颜色、表面质感 |
| JSON 光影权重（提示词比重） | 高 | 锁定光源方向、色温、阴影、氛围 |
| 输出分辨率 | 与原图一致 | 避免比例拉伸变形 |

**调优指南：**

- **构图跑偏、物体变形**：优先换用 GPT 2.5 纯轮廓线稿（方法 A）重新锁定构图；若已用 GPT 线稿，可在提示词中强化「严格保持参考图构图与透视」；OpenCV 线稿则提高 Canny 阈值让线稿更精简清晰
- **线稿太抽象/家具轮廓不完整**：OpenCV 线稿无法解决时直接改用 GPT 2.5 生成；生成结果若仍有残缺物体，在提示词第 3 条补列该物体名称
- **偏色未修正、材质不对**：核对 JSON 材质属性是否遗漏/错误，补充「整体色温与图二完全一致，杜绝冷灰偏色」
- **画面偏暖偏奶油（常见）**：检查光影 JSON 是否含「奶油」「清晨阳光」「暖白」等渲染词，一律改为「5000K 中性偏暖、纯白墙面、低饱和」，负向补「无过度暖调、无奶油色滤镜、无黄橙色偏色」
- **光影氛围不够**：细化光影 JSON 的光比反差/明暗层次/阴影/高光四项，并保留第五段氛围段落
- **产品细节模糊**：在正向提示词追加「产品轮廓清晰，表面质感细腻，结构分明」
- **单线稿仍不够**：可同时把图二作为第二参考图（image_paths 加图二 storage_key）三要素生成

## 六、输出验收标准

- 构图、人物姿态、产品位置与图一线稿完全一致
- 家具材质与 JSON 材质属性一致：胡桃木木纹、洞石纹理、布艺纤维感、哑光金属、鲜活叶片、通透肤色
- 光影与 JSON 光影属性一致：中性微暖自然光（量化目标：中性灰 R/B 比 ≈1.05~1.08、平均饱和度 ≈0.13~0.18，可抽样统计验证）、柔和阴影、细腻高光
- 画面整体**低饱和、中性微暖、干净明亮**，白色墙面纱帘为纯白，无明显奶油调/黄橙色偏色
- 产品造型准确，无变形、无多余元素
- 整体为真实商业摄影质感，无 AI 塑料感、油画感

## 七、负面约束清单

- 不改变画面构图、相机视角、透视
