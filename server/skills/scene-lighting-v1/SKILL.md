# 场景光影 · V1

定位：室内摄影灯光师与图像后期师。在已有照片上调整照明，不重新设计场景。底图定义所有物体与空间；参考只提供照明特征。技能提供规则与检查流程，不等于画布已接入生图接口，也不保证像素级结构锁定。

## 两种模式

- **光影优化（默认）**：保留原主光方向、光源布局和时间感，修正曝光、白平衡、暗部可读性、高光层次及局部光比。保持自然接触阴影，不强行提亮所有暗部，不新增窗影或戏剧性光束。
- **光影重塑**：用户明确选择后，可改变时间感、主光方向、光源软硬、色温与明暗分布。统一重算对应的投影、高光、反射、环境反弹及接触阴影；仍保持场景结构和家具不变。
- 优化模式中出现“改成夜晚、换主光方向”等重塑要求时，方案标记为重塑，并在执行前展示模式变化。用户已明确要求该变化时不重复索要许可。

## 必须保留

保持机位、透视、画幅比例、裁切、构图、物体数量、位置、尺度和几何结构。保持家具轮廓、坐垫、缝线、扶手、支腿、门窗位置及遮挡关系。
保持材质类别、纹理尺度与走向、家具固有色；允许光照导致合理的亮度、偏色及反射变化，不能把暖光变成木纹替换或把暗部当成新颜色。
人物身份、姿态、衣物和皮肤纹理不变；可随环境受到自然照明。产品结构、商标文字、印刷内容和屏幕内容保持；只有明确授权才改变已有灯具开关，产品指示灯不随场景灯具联动。
不移动人物或家具以露出遮挡表面，不新增灯具、窗户、装饰或文字。改变光向也不得凭空生成不存在的窗框投影。

## 胶囊参数

各组默认“沿用底图 / 自动”，用户未选择不额外添加风格。每组单选；已有灯具可按灯具分别设置。强度“轻微 / 适中 / 明显”是意图，不冒充模型 API 支持的精确控制参数。

| 参数组 | 建议选项 | 作用边界 |
| --- | --- | --- |
| 模式 | 光影优化、光影重塑 | 决定能否改主光和时间感 |
| 时间氛围 | 沿用、清晨、日间、傍晚、夜间 | 不改室外物体或空间布局 |
| 自然光 | 沿用、晴天柔光、阴天漫射、直射阳光 | 根据已有开口与光照证据解释；不额外造窗 |
| 主光方向 | 沿用、画面左、画面右、正面、侧后、顶部 | 以画面坐标描述，区分光源方位和投影方向 |
| 光影质感 | 沿用、柔和、适中、清晰硬影 | 软硬、对比、亮暗过渡联动 |
| 色温 | 沿用、中性、偏暖、偏冷 | 作用于光，不改物体固有色 |
| 已有灯具 | 沿用、开启、关闭 | 只处理底图已有照明灯具，不新增灯 |

时间、自然光、方向在优化模式中默认沿用；改变这些项时按重塑模式组织方案。多个胶囊组合成一套一致照明方案，不逐条堆叠互相冲突的提示词。
预设只填充这些参数，例如“柔和日光”“温暖傍晚”“夜间室内灯”；用户可逐项修改，预设不附带隐藏的材质或人物调整。

## 输入与优先级

必需：一张当前底图。可选：模式、胶囊参数、用户补充说明、光影参考图。V1 界面建议先支持一张主参考；多参考须明确主次，不平均混合冲突光向。

光影决策优先级：**用户补充说明 > 用户明确选择的胶囊 > 明确启用的光影参考 > 模式默认规则与底图推断**。
“沿用 / 自动”不是用户覆盖指令，不应屏蔽显式参考。未启用的参考或资产封面不参与生成。
补充说明如“保持沙发原色、灯不要打开”应覆盖暖光或开灯预设中的冲突项，保留其他兼容项。仅输出简短冲突处理结论，不输出内部推理过程。
保结构是本技能的任务范围。若补充要求换家具、改材质或改机位，应明确拆到相应功能；不要悄悄把光影节点变成场景重设计。

## 识别与生成流程

1. 读取底图：识别主要光源方向、明暗分布、阴影软硬、白平衡、已有灯具与开口；区分图中可见证据和推断，不宣称知道隐藏灯具的精确位置。
2. 若启用参考，只提取主光方向、光比、软硬、色温、时间感和环境反弹。参考中的家具、材料、人物、取景、装饰和文字不迁移。
3. 合并补充说明与胶囊，生成可读的单一照明方案。自然光和灯光相互补充；夜间无自然直射阳光，除非用户明确要求非写实效果。未知开口不虚构窗格，只描述合理的画外照明。
4. 向实际支持的图像编辑接口提交底图、必要参考与最终指令。先确认接口支持的参数，不编造强度、深度图或控制网络能力。光影是全图相互影响的编辑，不使用材质粗选区硬贴回原图，否则会切断投影和反射。
5. 保存原始生成结果、底图 ID、规则版本、模式、显式参数、补充说明、参考角色、冲突处理结果和任务 ID。预览默认完整结果，对比原图作为可选操作；不把合成图冒充原始输出。
6. 对照底图验收。没有真实生成或无权读取结果时，只能报告规则或代码检查完成，不能宣称效果已验证。失败保留原结果与原因，不自动无限付费重试。

## 最终生图指令骨架

“以图一为唯一场景结构依据，对该图执行【模式】。目标光照：【合并后的光照方案】。用户额外要求：【有效补充说明】。保持原机位、透视、裁切、所有家具和人物的数量、形状、尺度、位置与遮挡；保持材质类别、纹理、固有色和原有文字内容。只改变光照引起的亮度、色偏、高光、投影和反射，阴影与光源方向一致，保留接触阴影和自然细节。【有参考时：图二仅提供指定光影特征，不迁移其物体、材质或构图。】输出完整照片，不添加说明文字、标记或分屏。”

骨架是模板，提交前替换占位项并删去不适用句。优化模式补充“保留原主光方向和时间感”；重塑模式明确新的主光和时间感。不要把原始 UI 标签、整个技能文档或矛盾选项直接作为提示词。

## 验收标准

- 结构：对照家具外轮廓、支腿、窗框、人物关节、产品边缘和文字位置；发生重排或形变则需复核。
- 光影：目标时间与光向是否执行；投影、高光和镜面反射是否一致；人物与家具是否处于同一照明环境；接触处不漂浮。
- 材质：不因提亮或变暖替换固有色与材质，不磨平纹理，不出现塑料感或过度 HDR。
- 图像：无死白高光、堵死暗部、边缘光晕、局部贴补接缝；原有文字不新增、移位或改写。
- 只报告可观察的通过项和问题。参考不兼容、光源不确定或无法判定时明确标为待复核。

## 画布接入约定

节点建议顺序：底图 → 可选光影参考 → 优化/重塑 → 胶囊摘要与展开设置 → 生图参数 → 补充说明 → 生成。
补充说明只在画布节点保留一个输入。首屏展示已选胶囊，默认项不堆叠；无选择时显示“沿用底图光影，优化曝光与层次”。
本文件属于 V1 技能定义。应用需将本规则加入独立光影请求构建、任务保存和结果验收链路，才能真正生效；保存或安装技能不等于自动启用节点。规则后续变更发布新版本，任务记录使用的版本。
