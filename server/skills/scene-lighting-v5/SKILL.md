# 场景光影 · V5

定位：室内摄影灯光师与图像后期师。在已有照片上调整照明，不重新设计场景。底图定义所有物体与空间；本版不使用额外光影参考图。技能提供规则与检查流程，不等于画布已接入生图接口，也不保证像素级结构锁定。

## 两种模式

- **光影优化（默认）**：保留原主光方向、光源布局和时间感，修正曝光、白平衡、暗部可读性、高光层次及局部光比。保持自然接触阴影，不强行提亮所有暗部，不新增窗影或戏剧性光束。
- **光影重塑**：用户明确选择后，可改变时间感、主光方向、光源软硬、色温与明暗分布。统一重算对应的投影、高光、反射、环境反弹及接触阴影；仍保持场景结构和家具不变。
- 优化模式中出现“改成夜晚、换主光方向”等重塑要求时，方案标记为重塑，并在执行前展示模式变化。用户已明确要求该变化时不重复索要许可。

## 必须保留

保持机位、透视、画幅比例、裁切、构图、物体数量、位置、尺度和几何结构。保持家具轮廓、坐垫、缝线、扶手、支腿、门窗位置及遮挡关系。
保持材质类别、纹理尺度与走向、家具固有色；允许光照导致合理的亮度、偏色及反射变化，不能把暖光变成木纹替换或把暗部当成新颜色。
人物身份、姿态、衣物和皮肤纹理不变；可随环境受到自然照明。产品结构、商标文字、印刷内容和屏幕内容保持；只有明确授权才改变已有灯具开关，产品指示灯不随场景灯具联动。
不移动人物或家具以露出遮挡表面，不新增灯具、窗户、装饰或文字。改变光向也不得凭空生成不存在的窗框投影。

## 自然光控制（主要交互）

将室内自然光拆为窗户进入的天空环境光与太阳直射光。环境光决定基础明暗和柔和过渡，直射光决定阳光照射区域、投影与局部光比。人工灯光单独保留，不能将所有光都误判为太阳光。

| 控制 | 设定 | 执行规则 |
| --- | --- | --- |
| 阳光开关 | 关闭 / 开启，初始沿用底图识别状态 | 关闭只去除太阳直射成分，保留合理环境光、接触阴影及已有灯光；开启依据已有入光路径增加直射光，不必然产生可见空气光束 |
| 色温滑块 | 偏冷 ← 中性 → 偏暖；归一化 -100～100，0 为中性 | 控制自然光的冷暖倾向；不是全图滤镜，不改变家具固有色，不强制覆盖人工灯具色温 |
| 阳光强度 | 0～100，从微弱到明显 | 控制直射光相对环境光的强弱，不等于整图曝光；0 表示无直射贡献，100 也应保留高光层次，不模拟无限亮度 |
| 阴影软硬 | 0～100，从柔和到清晰 | 调整太阳直射投影的边缘过渡，结合窗帘、遮挡和光源合理性；不抹除接触阴影，不改变物体几何 |

阳光关闭时，阳光强度和太阳阴影软硬项停用，保存原值便于重新开启，但不把停用项写入当前生图目标。色温仍作用于自然环境光。只调色温不能擅自开启太阳光、改变太阳方位或切换时间。
滑块值是产品内的归一化意图，转换为连续、适量的描述，不声称是模型 API 原生的精确光照参数，不标注未经标定的开尔文读数。

### 初始值与显式操作

默认沿用底图，先识别再展示估计值。持久化区分“未设置 / 沿用”与用户明确设置的数值或开关；色温 0 和强度 0 都是有效值，不能当作缺省。未识别前显示“沿用底图”，不能因为滑块居中就自动提交中性色温。
用户拖动后该项成为显式覆盖；“恢复底图”清除覆盖状态。底图是夜景或封闭空间时，不默认凭空加入日光；用户主动开启阳光时将其作为重塑意图，并说明对时间感的影响。

### 自动入光识别

优先结合底图可见窗户、门洞、窗帘透光及已有投影识别入光位置和方向。窗户不在画面中时，可根据明暗与投影推断画外光源，并标记为推断；不凭空造窗或窗格投影。
同一窗户的环境光与直射阳光共享合理入光路径；投影方向与光源方向相反，家具、人物和地面受同一套光照约束。
多窗时默认保留底图主光关系，在更多设置提供“主入光窗”选择。无法可靠判定时沿用现有明暗关系，不强制用户每次选择方向，也不伪造确定的光源坐标。

### 更多设置

主界面不堆叠时间、天气、方向等胶囊。优化/重塑模式、主入光窗、时间氛围、手动光向和已有人工灯具放入更多设置。人工灯具默认沿用，只能开关底图已有照明灯具，不能新增灯或改产品指示灯。
保留默认优化模式。仅微调强度、冷暖和软硬可作为优化；开关阳光实际改变底图照明状态、改变主光向或时间时属于重塑。自动呈现模式变化，不要求用户再重复配置已表达的意图。
预设若保留，只填充上述可见参数，不附带隐藏材质、构图、人物或装饰调整。

## 输入与优先级

本版仅使用一张底图、自然光控制参数和补充说明，不展示或提交额外参考图。旧版保存的 referenceIds 不参与光影生成，不能将其他连入图片自动当作参考。
光影决策优先级：**用户补充说明 > 用户明确设置的开关、滑块或更多设置 > 底图识别与默认规则**。
未操作的参数沿用底图，不等于显式选择中性或中等强度。先解决冲突再输出单一照明方案。补充说明只在节点保留一个输入。
保结构是本技能的任务范围，换家具、改材质、改机位应拆到相应功能。

## 识别与生成流程

1. 读取底图：识别主要光源方向、明暗分布、阴影软硬、白平衡、已有灯具与开口；区分图中可见证据和推断，不宣称知道隐藏灯具的精确位置。
2. 只根据底图识别环境光与直射阳光，不读取额外参考；将识别结果与用户显式操作区分保存。
3. 合并补充说明与显式参数，生成可读的单一照明方案。自然光和灯光相互补充；夜间无自然直射阳光，除非用户明确要求非写实效果。未知开口不虚构窗格，只描述合理的画外照明。
4. 向实际支持的图像编辑接口提交底图与最终指令。先确认接口支持的参数，不编造强度、深度图或控制网络能力。光影是全图相互影响的编辑，不使用材质粗选区硬贴回原图，否则会切断投影和反射。
5. 保存原始生成结果、底图 ID、规则版本、模式、显式参数、补充说明、冲突处理结果和任务 ID。预览默认完整结果，对比原图作为可选操作；不把合成图冒充原始输出。
6. 对照底图验收。没有真实生成或无权读取结果时，只能报告规则或代码检查完成，不能宣称效果已验证。失败保留原结果与原因，不自动无限付费重试。

## 最终生图指令骨架

“以图一为唯一场景结构依据，对该图执行【模式】。目标光照：【合并后的光照方案】。用户额外要求：【有效补充说明】。保持原机位、透视、裁切、所有家具和人物的数量、形状、尺度、位置与遮挡；保持材质类别、纹理、固有色和原有文字内容。只改变光照引起的亮度、色偏、高光、投影和反射，阴影与光源方向一致，保留接触阴影和自然细节。输出完整照片，不添加说明文字、标记或分屏。”

骨架是模板，提交前替换占位项并删去不适用句。优化模式补充“保留原主光方向和时间感”；重塑模式明确新的主光和时间感。不要把原始 UI 标签、整个技能文档或矛盾选项直接作为提示词。

## 验收标准

- 结构：对照家具外轮廓、支腿、窗框、人物关节、产品边缘和文字位置；发生重排或形变则需复核。
- 光影：检查阳光关闭时是否保留环境光，色温调整是否误改材料或灯具，停用参数是否泄漏到指令；目标时间与光向是否执行；投影、高光和镜面反射是否一致；人物与家具是否处于同一照明环境；接触处不漂浮。
- 材质：不因提亮或变暖替换固有色与材质，不磨平纹理，不出现塑料感或过度 HDR。
- 图像：无死白高光、堵死暗部、边缘光晕、局部贴补接缝；原有文字不新增、移位或改写。
- 只报告可观察的通过项和问题。光源不确定或无法判定时明确标为待复核。

## 画布接入约定

节点建议顺序：底图 → 阳光开关 → 色温滑块 → 阳光强度与阴影软硬 → 更多设置 → 生图参数 → 补充说明 → 生成。
补充说明只在画布节点保留一个输入。首屏展示自然光控制，人工灯光与高级参数折叠；未操作时显示“沿用底图光影，优化曝光与层次”。
本文件属于 V5 技能定义。应用需将本规则加入独立光影请求构建、任务保存和结果验收链路，才能真正生效；保存或安装技能不等于自动启用节点。规则后续变更发布新版本，任务记录使用的版本。

## V5 天气、时间与外景模块

所有模块支持启用、停用、移除和排序。未启用、移除或仅缓存的值不参与生成；“沿用”不覆盖底图。用户补充说明仍具有最高优先级。

- 天气胶囊：沿用、晴天、阴天、雨天。晴天不自动启用直射阳光；阴天以天空漫射为主；雨天降水仅在已有窗外，不新增室内雨水、湿地面或玻璃雨滴。阴雨与显式阳光并存时可解释为云隙透光，不堆叠矛盾的照明状态。
- 时间胶囊：沿用、清晨、正午、午后、夜晚。夜晚与太阳直射冲突时默认时间优先，去除直射光及其强度和软硬，记录调整原因；仍允许补充说明明确覆盖。夜晚不自动打开所有室内灯具。手动色温优先于时段的惯常冷暖。
- 外景胶囊：沿用、小区、城市、森林、海洋。这是用户明确授权的局部窗外内容替换，作为本技能原有“仅改光影”范围的例外；不授权改变室内场景。仅修改已有窗中实际可见的室外景观，保持窗框、玻璃、窗帘、遮挡和透视。无可见窗外区域时不造窗、不变成壁画。未选择时保持原外景。
- 天气、时间或外景的明确改变按重塑组织方案，其余结构和材质保护继续生效。提示词包含有效选项、保留约束及冲突处理规则；任务记录技能版本、最终有效参数和调整原因。
- 界面滑块悬停显示 grab，按住时显示 grabbing；停用滑块显示不可调状态。光标只影响滑块交互，不触发画布平移。
- 验收新增：天气与时段一致，夜晚无误加太阳光，雨水不进入室内；外景仅限授权窗外区域，窗框、人物和家具保持。

## V5 外景结构门控（优先于前述外景规则）

外景选择不能授权新增任何窗户、门洞、墙体开口或改变取景。结构保护优先于所有参数及补充说明。
提交前检查原始底图是否存在真实且直接可见的室外区域。只有 visibleExterior=true、confidence=high 且给出实际区域描述时才传递外景目标；否则从有效参数和最终提示词移除所选景观，不仅追加“不要开窗”的负面提醒。
画框、镜子、电视、窗影、墙面光斑、完全遮挡的窗口与推断的画外光源不算可见外景。分析接口失败或不确定时也停用外景，并保存调整原因，不凭空补窗。
保留用户选项用于后续编辑，但本次任务保存实际生效参数及检查依据。已提交的旧任务不受新规则影响，不自动重新收费生成。
已确认可见外景时仍须保持窗口原有尺寸、位置、边界、窗框、窗帘、透视与遮挡。生成模型可能偏离指令；结果出现新窗或结构改变必须标为需复核，不能声称门控等于像素级结构保证。
