# Visual Workspace 画板使用手册

版本日期：2026 年 10 月 21 日｜适用对象：设计师、素材制作同事、首次安装用户

本手册按当前画板实现编写。下方案例是可复现的操作练习和提示词示例，不代表已经生成或验收的成品。真实生图和视觉分析会消耗对应平台额度。

## 1. 先了解画板能做什么

画板把参考图、生成任务、结果图和素材放在同一个无限画布中，通过连线保留它们之间的关系。可以创建多个项目，做文生图、多图参考生成、资产提取、材质调整、扩图以及部分本地图像处理。

推荐第一次使用顺序：新建项目 → 导入图片 → 提交一个单张任务 → 查看结果 → 修改再生成 → 导出项目。

### 三类配置，作用不同

| 配置 | 用途 | 没配置时的表现 |
| --- | --- | --- |
| DREO 生图接口 | 文生图、参考图生成、扩图及需要生图的资产预览 | 无法提交对应生成任务 |
| 视觉分析接口 | 看图识别对象、材质，以及部分编辑前的分析 | 提示“视觉分析接口未配置” |
| 本地模型运行环境 | 去背景、消除、变清晰、多图层 | 对应功能报模型或运行环境未就绪 |

技能规则和提示词已随代码提供，但它们不能替代模型接口。只安装画板不等于全部 AI 功能已就绪。

## 2. 安装与每天启动

源码地址：https://github.com/qq1691995569-droid/visual-workspace

首次安装请阅读同目录 TEAM_SETUP.md 和 CONTINUE_AT_HOME.md。使用 main 最新源码，不用旧 ZIP 快照覆盖当前文件。

已安装好的 Windows 用户：

1. 进入画板项目目录，双击 `Start-Canvas.cmd`。
2. 等待服务启动，在浏览器打开 `http://127.0.0.1:5173/`。
3. 使用期间保留服务窗口。关闭窗口后，画板后台接口也会停止。

若没有启动脚本，可在项目目录执行：

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

固定使用同一个浏览器和地址。`localhost`、`127.0.0.1`、不同端口和不同浏览器使用的本地存储可能不同。这个地址只指向使用者自己的电脑，不是团队在线网站。

### 使用管理员提供的视觉配置安装包

1. 将安装包解压到项目目录以外的文件夹。
2. 双击 `Install.cmd`，输入画板项目根目录。
3. 安装后重启画板服务，再重新提交资产提取。

安装包只配置视觉分析，不配置个人 DREO 生图凭据。它会备份原 `.env.local` 并保留其他设置。共享配置含可读取的密钥，只通过指定渠道传递，不放进 GitHub 或公开网盘。

## 3. 项目管理与保存

点击右上角“项目管理”，可新建、打开、搜索项目，按更新时间或名称排序。项目卡片菜单可重命名、复制、移入回收站；回收站中的项目可以恢复。

- 画布自动保存在本机浏览器。清理网站数据可能丢失本地项目。
- 右上角“导出项目”保存 `.visproj` 文件；在项目管理中“导入项目”恢复。
- 复制项目适合开始新一轮方案，避免直接改动原方案。
- GitHub 保存程序代码，不自动同步画布、资产库和任务记录。
- 给同事交付已有画布，应发送导出的 `.visproj`。资产库需要另外备份和导入。

建议命名：`项目编号_产品_用途_日期`，例如 `PP02_桌面风扇_客厅场景_1021`。

## 4. 画布基本操作

| 操作 | 方法 |
| --- | --- |
| 导入图片 | 右上角“导入图片”；也可拖入图片 |
| 移动图片 | 拖动图片节点 |
| 移动画布 | 按住鼠标中键拖动 |
| 缩放 | 滚轮；或左下角缩放按钮 |
| 查看图片 | 双击图片打开预览 |
| 多选图片 | Shift 配合点击，或空白处框选 |
| 添加生成参考 | 自由编辑中按 Ctrl / Command 点击画布图片，或“上传参考” |
| 删除选中节点 | Delete / Backspace（输入文字时不要误当画布删除使用） |
| 提交生成 | 点击“生成图片”，或在提示词输入框按 Ctrl / Command + Enter |
| 对比两张图片 | 选中恰好两张可用图片，按空格打开滑块对比；不要在输入框中操作 |

连线用于表示输入与结果关系。选择图像节点的连接点，可连接参考图与生成节点。不要把连线理解为图片内容已经被模型执行处理。

### 创作框的最新行为

- 提交底部创作任务并创建任务框后，提示词、参考图和参数立即重置，方便开始下一轮。
- 单击画布空白处，也会清空当前创作输入。未提交的文字不会成为任务历史，长提示词建议另存。
- 点选普通生成任务框或结果图，可恢复这一轮的提示词、参考图和生成参数，再修改或生成。
- Ctrl / Command 点击用于添加参考，不是恢复历史。
- 技能生成结果通过“沿用技能”继续对应技能流程，不同于普通生成历史恢复。
- 原参考图被删除后，历史中的参考可能不可用，需要移除失效项或重新添加。

## 5. 文生图和多图参考生成

### 文生图

选择“文生图”，描述主体、场景、机位、光线和需要保留的细节。设置模型、分辨率、比例和张数后提交。

### 图生图

选择“图生图”，添加参考图，在提示词中用“图1、图2……”明确分工。参考顺序要与描述一致，删除或调整参考后重新检查编号。

参数以当前模型和 DREO 接口返回的能力为准：画板输出上限为 4 张；部分模型有更严格的张数、参考图数量、尺寸和质量限制。界面可添加参考不代表每个模型都支持相同数量。不要把 2K 当作所有比例都固定 2048×2048，最终以结果尺寸为准。

建议首次验证用 1 张，确认接口、产品结构和画面方向后再增加张数。

## 6. 图片工具栏说明

选中图片后，上方出现操作栏。

| 工具 | 怎么使用 / 输出 | 当前依赖与限制 |
| --- | --- | --- |
| 编辑 | 输入修改要求，生成编辑结果 | DREO 生图；AI 可能改变细节 |
| 引用生成 | 使用当前图片作为参考开展新创作 | DREO 生图；检查参考列表和模型 |
| 提取资产 | 指定要提取的对象或材质，分析并生成预览，确认后保存 | 视觉分析 + DREO；不是简单裁剪，需核对资产外观 |
| 多图层 | 将画面拆为独立透明图层组 | 本地 Qwen-Image-Layered + ComfyUI；默认 640 分辨率、4 层、20 步；仍需效果验收 |
| 去背景 | 输出带透明通道的图片 | 本地 BiRefNet General；复杂家具、细小产品可能漏掉 |
| 消除 | 涂抹不需要的区域后执行修复 | 本地 LaMa；仅合成选区，检查边缘和纹理 |
| 扩图 | 调整扩展框，填写外围画面要求后提交 | DREO + 本地合成；检查接缝、光影及主体是否变化 |
| 变清晰 | 对图像执行本地增强 | Real-ESRGAN_x2plus；当前默认返回原尺寸，不是默认两倍输出，也不是 Topaz |
| 下载 | 下载当前图片 | 分享透明图时检查文件透明通道是否保留 |

DREO 的 ADI TTP 放大与“效果图放大（之前默认放大）”尚未接通；它们不是当前“变清晰”的功能。Topaz 也尚未接入。

## 7. 案例一：从文字生成客厅场景

**目标**：先确定场景风格，不要求还原某个具体产品型号。

**准备**：DREO 生图配置就绪。新建 `练习01_客厅场景` 项目。

**步骤**：选择文生图 → 粘贴以下描述 → 选可用模型、16:9、2K、1 张 → 生成。

```text
生成一张写实家居摄影。浅米色客厅，左侧大窗提供柔和自然光，亚麻沙发、浅橡木边桌与少量绿植。镜头与坐姿视线接近，保留真实空间比例。边桌上放置一台简洁的桌面风扇，作为视觉主体。画面干净克制，材质真实，不添加文字、海报、水印或多余装饰。
```

**检查**：构图是否清晰、家具比例是否合理、产品是否像真实物体。此案例为概念图；需要准确 SKU 外观时改用下一案例，不能只凭文字保证产品一致。

**继续**：点击结果图，恢复描述，将“柔和自然光”改为“下午斜射阳光”，再次提交。点击空白处则开始一轮空白创作。

## 8. 案例二：产品 + 场景 + 材质，多图组合

**目标**：把指定产品放进参考客厅，同时控制沙发材质。

**准备**：图1 为产品清晰参考；图2 为客厅构图；图3 为面料参考。优先用主体完整、无遮挡、分辨率足够的图片。

**步骤**：导入三张图 → 图生图 → 按 Ctrl 点击，按顺序加入参考 → 检查编号 → 填写提示词 → 先生成 1 张。

```text
图1是产品外观依据，保留它的轮廓、比例、颜色、出风口、按键和底座结构，不增加零件。
图2是场景与机位依据，保留沙发、边桌、窗户位置和透视，将图1产品自然放在边桌上，产品尺度与桌面匹配。
图3只用于沙发表面面料，参考其织物颜色和细密纹理，不改变沙发造型，不把面料应用到产品。
统一采用图2的光线方向，补充合理接触阴影。输出写实摄影，不添加文字或额外产品。
```

**检查**：产品零件有没有变化、桌面接触阴影是否自然、图3是否只影响沙发。如果产品结构错误，不要通过盲目多次生成掩盖问题，应减少冲突描述或换更清楚的产品参考。

**继续**：点结果恢复本轮输入，把材质描述改为更浅的米灰色再生成。不要误以为恢复输入就自动把结果图加入了参考；需要基于结果再改时，使用“引用生成”并检查参考列表。

## 9. 案例三：提取沙发面料并复用

**目标**：将满意场景里的面料整理成可复用资产。

**准备**：DREO 生图和视觉分析两套配置都就绪。

1. 选中包含沙发的图片，点击“提取资产”。
2. 指定清晰对象，例如“左侧沙发的米灰色织物面料”，避免仅写“材质”。
3. 提交后查看画布中的提取任务和预览。
4. 核对名称、色相、纹理尺度和提示词。确认后保存到资产库。
5. 在新的场景中使用材质优化流程，点选目标对象，再从资产库绑定该材质。
6. 保存绑定并回到画布提交生成，检查选区边界与非目标区域。

**示例要求**：

```text
提取左侧沙发的米灰色亚麻织物材质。保留细密交织纹理、低饱和色相和柔软漫反射，不把窗户阴影、沙发接缝或木质扶手当作材质纹理。
```

**检查**：提取预览可能由模型重建，不等于原图的精确像素切片。颜色被场景光线影响时，应结合产品或面料实拍复核。

**常见阻塞**：若直接出现“视觉分析接口未配置”，先安装视觉配置并重启，不要重复点生成。

## 10. 案例四：竖图扩成横版展示图

**目标**：保留主体，将竖版客厅图扩成横向展示构图。

1. 选中原图，点击“扩图”。
2. 调整扩展框，给需要延伸的一侧留空间，尽量避免一次扩得过大。
3. 填写下方要求并提交。
4. 对比原图与结果，检查墙面、地板、窗帘等跨边界位置。

```text
沿原场景向两侧自然延伸，保持原有机位、地板透视、墙面色温和窗光方向。延续已有家具与空间逻辑，不重复人物或产品，不添加文字，不在原图边缘形成边框、拼贴或明显色块。
```

**检查**：主体有没有移动或变形、原图边界有没有色差、地板线条是否衔接。若提示对齐检查失败，表示程序未接受合成结果，应缩小扩展范围或更换模型后重试，不把失败占位图当成可交付结果。

## 11. 案例五：清除杂物与增强图片

**目标**：清除桌上的小杂物，再做轻量清晰度增强。

1. 先复制项目或保留原图，选图片点击“消除”。
2. 涂抹杂物，包含必要边缘，但不要覆盖产品轮廓或大面积桌面。
3. 提交后检查木纹、桌面直线、阴影是否连续。
4. 对满意结果使用“变清晰”，放大预览比较纹理、文字、Logo。

**检查**：LaMa 会推断被遮挡内容；Real-ESRGAN 可能生成不真实纹理。当前变清晰默认输出原尺寸，不适合作为“已经得到两倍尺寸”的交付依据。

本地模型未安装的同事可以先完成前四个案例中的远端流程，不要反复重试尚未部署的本地工具。

## 12. 案例六：把方案交给同事继续做

1. 将项目重命名为 `PP02_风扇客厅_方案A_1021`。
2. 导出 `.visproj`，通过团队认可的渠道发送。
3. 同事启动自己的画板，进入项目管理并导入。
4. 同事点选普通生成结果，可查看原参考与提示词，再修改生成。
5. 若要共享资产库，另做资产备份和导入。

代码仓库、画布文件和接口配置是三份不同内容。不要把带密钥的安装包或 `.env.local` 放进项目素材文件夹一起公开分享。未完成任务依赖原机器的后台记录，换电脑后不保证能继续恢复；尽量交付已完成项目。

## 13. 任务状态与排错

| 现象 | 含义 | 建议处理 |
| --- | --- | --- |
| 正在上传参考图 / 生成中 | 任务在传图、排队或处理 | 保持服务运行，观察状态，不连续重复提交 |
| 查询中 / 恢复任务 | 正在尝试查询已有任务，不是自动再生成 | 等待查询；若长期不变，核对服务和任务状态 |
| 需处理 / 已暂停 | 配置缺失、请求错误或无法确认任务状态 | 阅读具体报错再操作 |
| 视觉分析接口未配置 | 缺少看图模型地址、密钥或模型名 | 安装视觉配置、重启服务后重新提取 |
| DREO 本机凭据未配置 | 缺少个人 DREO 配置 | 按接入指南配置，不用 OpenLux 密钥替代 |
| 401 / 403 | 通常与认证或权限有关 | 核对对应平台的密钥有效性和账号权限 |
| HTTP 500 | 接口服务端发生错误 | 保留任务信息交给管理员，不要高频重试 |
| 本地模型未就绪 | 权重或运行环境缺失 | 按 LOCAL_VISION.md 部署，或先使用已配置功能 |
| 浏览器拒绝连接 | 本机服务没有监听该端口等 | 重新启动服务，检查终端错误和地址 |
| 更换浏览器后项目不见了 | 使用了另一份浏览器存储 | 回原浏览器导出，再在新浏览器导入 |
| 删除任务后平台仍显示处理中 | 本地删除不保证远端立即取消 | 到平台核对任务，避免重复提交消耗额度 |

删除任务会停止本地跟踪并丢弃迟到结果，但不能保证已经发出的远端计算立即停止。失败后重新生成前，应先判断是否已有远端任务，避免重复计费。

## 14. 交付前检查

- 产品轮廓、按键、Logo、数量和比例是否正确。
- 人物手部、家具边缘、透明区域及阴影是否自然。
- 扩图是否存在拼接、重影和重复对象。
- 材质调整有没有误改产品或其他家具。
- 下载结果实际尺寸是否符合用途，而不是仅看“2K”标签。
- 已导出项目和需要的资产备份；密钥没有混入公开文件。

## 15. 当前边界

画板是本地应用，不具备团队实时协同和自动云端资产同步。去背景在复杂家具场景下仍可能漏掉前景；多图层的语义拆分和遮挡恢复需要人工验收。工具已接入不等于任意电脑无需部署即可使用。模型参数与可用性以所在账号接口返回为准。

遇到问题请提供：操作名称、任务状态、错误文字、发生时间、是否已配置对应接口。不要提供完整 API 密钥或 Cookie。
