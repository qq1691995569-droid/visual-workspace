# 本机 API 管理

后台 `/admin` 的「API 管理」统一显示已接入的接口和各功能的接口分配。管理员只能为功能选择服务端明确声明兼容的接口；未配置凭据的接口不能保存。路由配置保存在忽略版本控制的 `.canvas-data/api-routing.json`，凭据仍在各自本机配置文件中，接口响应不包含 Token。旧版 `.canvas-data/separation-provider.json` 会作为多图层选择读取；首次保存新配置后使用新文件。

当前「多图层」和「框选编辑」分别支持 OpenLux 与 DREO 两个适配器，新任务各自读取 `separate`、`interactive-edit` 的接口选择；已配置 OpenLux 时默认使用 OpenLux。普通生图和未使用框选的旧版图片编辑仍走 DREO。框选编辑按原图 0–999 归一化坐标生成 `<bbox>` 提示词，并固定调用 Seedream 5.0 Pro；OpenLux 返回单张结果后才下载保存，不自动重提不确定的请求。DREO 原生拆层能力尚未由服务端确认，凭据状态不代表能力校验通过。切换不重提已有任务，也不影响其他功能。

接入后续功能时，在 `server/api-routing.mjs` 的 `apiRouteDefinitions` 登记功能 ID、名称和已实现的兼容接口；执行器创建新任务时读取对应功能 ID 的选择，并在任务记录中保存接口 ID。若新增服务采用不同请求或响应格式，先实现并验证该服务的适配器及本机凭据检查，再把它加入兼容列表。后台列表按登记项自动显示，无需为每个功能增加新的管理页面。仅填写一个 URL 无法使不同协议自动兼容。
