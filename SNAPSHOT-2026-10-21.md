## Restore

Run `npm.cmd ci`, copy `.env.example` to `.env.local`, configure Python with Pillow/numpy, then run `npm.cmd run dev -- --host 127.0.0.1 --port 5173`.

Server-only configuration (supply your own keys locally):

- DREO origin: https://ai.shawshao.com:4443
- DREO credentials: ~/.dreo-visual-lab/credentials.json, fields origin and token.
- CANVAS_VISION_ENDPOINT=https://api.openlux.ai/v1/chat/completions
- CANVAS_VISION_MODEL=gemini-3.8-flash
- CANVAS_VISION_TOKEN: fill locally, never commit.
